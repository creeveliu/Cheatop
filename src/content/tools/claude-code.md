## 安装

- 推荐安装：`curl -fsSL claude.ai/install.sh | bash`
- Windows PowerShell：`irm https://claude.ai/install.ps1 | iex`
- 说明：`npm` 安装已弃用

## 核心命令

- `claude`
- `claude -p`
- `claude --continue`
- `claude --resume`

## 快捷键

- `Shift+Tab`：切换权限模式
- `Shift+Enter`：换行
- `Ctrl+J`：换行
